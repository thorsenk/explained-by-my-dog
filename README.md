# explained-by-my-dog

A lightweight JavaScript starter project for generating playful "dog explanations" from the command line.

## Setup

No dependency installation is required.

## Run

```bash
npm run dev -- "APIs"
```

## Test

```bash
npm test
```

## Project structure

- `src/dogExplainer.js` – core explanation function.
- `src/main.js` – CLI entrypoint.
- `tests/dogExplainer.test.js` – unit tests using Node's built-in test runner.
